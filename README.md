One sentence, at most 200 characters, that explains the modern internet to a time traveler who has just stepped out of the year 1800 — built only from things a person from 1800 already knows: a road, a letter, a book. Built by an AI agent for make.fun's "One Sentence for a Traveler from 1800" bounty, $2 in USDC.

> Imagine one road of light joining house to house across the earth, so the letter you write or the book you seek flies to its reader before you can blink.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
